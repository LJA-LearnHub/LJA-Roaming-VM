Mastering IP Subnetting

Understand Class A, B, and C IPv4 Networks

Class A Networks

Designed for large-scale networks with millions of hosts.

First Octet Range1 – 126
Default Mask255.0.0.0 ( /8 )
Network Bits8
Host Bits24
Hosts per Net16,777,214

Class B Networks

Designed for medium-sized networks like universities or enterprise corporations.

First Octet Range128 – 191
Default Mask255.255.0.0 ( /16 )
Network Bits16
Host Bits16
Hosts per Net65,534

Class C Networks

Designed for small local area networks (LANs).

First Octet Range192 – 223
Default Mask255.255.255.0 ( /24 )
Network Bits24
Host Bits8
Hosts per Net254

Core Subnetting Formulas

  • Number of Subnets created: 2^s (where s is the number of borrowed bits).
  • Usable Hosts per Subnet: (2^h) - 2 (where h is the remaining host bits). Subtract 2 for Network ID and Broadcast Address.
  • Block Size (Magic Number): 256 - Subnet Octet Value
